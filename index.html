Моя первая веб-страница

Веб-разработка — это процесс создания веб-сайтов и приложений для интернета. Она включает в себя верстку страниц, написание логики и настройку серверной части.

В ходе этого курса я хочу научиться создавать современные, адаптивные и красивые веб-страницы, а также освоить базовые технологии фронтенда.

Технологии, связанные с веб-разработкой:

  • HTML (разметка)
  • CSS (стилизация)
  • JavaScript (интерактивность)
  • Git (система контроля версий)

Полезный ресурс для изучения: MDN Web Docs

Мои цели

  1. Глубоко изучить HTML5 и CSS3.
  2. Научиться писать чистый и семантичный код на JavaScript.
  3. Создать свое первое полноценное портфолио.
